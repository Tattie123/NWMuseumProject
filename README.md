<h2>Deployment</h2>
<p>Recommended Database Installation Instructions<br>

- Follow Default Xampp Installation Instructions.<br>
- Open the Xampp Control Panel.<br>
- Start Apache.<br>
- Start MySQL.<br>
- Press the Admin Action for MySQL.<br>
- Press the IMPORT button and select CreationSchema.sql, press the Import button.</p>

<p>
Download Release from github
  
- Double click on the Start.bat file.<br>

- To Login as other user the username and password is:

- **All logins are lower case:**

  | Feature | Login as Staff | Login as Manager |
  |---------|----------|----------|
  | UserName| staff    | manager  |
  | Password| staff    | manager  |
  
> [!NOTE]
> You may need to edit your MySQL `.ini` configuration file to allow a larger packet size, depending on the size of the images you upload.

> [!TIP]
> To upload images, either drag and drop them onto the page or click the upload button to open the file browser.
